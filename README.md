# WellnessTracker

## Overview

WellnessTracker is an Android mobile application developed independently using Kotlin and SQLite. The application helps users track and manage their daily wellness and health-related activities efficiently.

## Features

- Track daily wellness activities
- Manage health-related records
- Update and monitor wellness information
- Store data locally using SQLite
- User-friendly Android interface

## Technologies Used

- Kotlin
- Android Studio
- SQLite
- XML
